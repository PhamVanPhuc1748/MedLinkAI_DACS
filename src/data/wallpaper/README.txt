CÁCH SỬ DỤNG:
  1. Đặt file ảnh vào thư mục này (src/data/wallpaper/)
  2. Reload trang web — ảnh tự động được áp dụng
  3. Không cần sửa bất kỳ file code nào

ĐỊNH DẠNG HỖ TRỢ:
  .jpg / .jpeg    ← khuyến nghị (dung lượng nhỏ, chất lượng tốt)
  .png            ← nếu cần nền trong suốt
  .webp           ← dung lượng nhỏ nhất
  .gif            ← ảnh động (không khuyến khích cho nền)

KÍCH THƯỚC GỢI Ý:
  Tối thiểu: 1280×720 px
  Lý tưởng : 1920×1080 px hoặc lớn hơn
  Tỷ lệ    : 16:9 hoặc rộng hơn (landscape)

NẾU CÓ NHIỀU ẢNH:
  Hệ thống dùng ảnh đầu tiên theo thứ tự tên file (A→Z).
  Gợi ý đặt tên: 01_ten_anh.jpg, 02_ten_anh.jpg, ...
  Để chuyển ảnh: xóa hoặc đổi tên file cũ trước khi thêm ảnh mới.

THỨ TỰ ƯU TIÊN (nếu thư mục trống):
  1. src/data/assets/bg_landing.jpg   ← ảnh cũ (nếu có)
  2. Ảnh mặc định từ Unsplash (cần internet)
